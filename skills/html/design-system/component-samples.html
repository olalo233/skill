网页为什么需要两套配色？

白天清晰，夜晚舒适。好的明暗适配，让内容保持熟悉，也让阅读更轻松。

阅读约 3 分钟

  1. 先建立层级
  2. 为颜色命名
  3. 检查可读性
  4. 试着读一段

先建立层级，再考虑颜色

读一篇文章时，视线应该先找到标题，再自然地进入正文。标题、解释、图表和注释各有分量，不需要同样醒目。

留白把段落分开，字重提示内容的重要性。边框只在确实需要区分区域时出现。这样，即使页面换成另一套配色，信息的顺序仍然清楚。

阅读界面的装饰，应当帮助内容被理解。

给颜色一个稳定的角色

同一个“正文色”，在浅色下接近深灰，在暗色下接近浅灰。内容引用这个角色，系统外观决定它最终呈现的颜色。

角色使用位置视觉分量
主要文字标题、重要结论最清晰
正文文字段落、列表、表格清楚、稳定
辅助文字图注、日期、说明安静但可读
结构分隔表格横线、区域边界轻量

例如，正文只需要引用两个变量。两套配色保存在共享样式里，不必再写一份页面。

body {
  background: var(--mb-bg);
  color: var(--mb-ink-body);
}

变暗之后，也要读得清楚

试着读一段

调整字号，看看同一段话如何适应你的阅读习惯。系统明暗切换仍由设备控制。

阅读是一段连续的过程。适当的行距和段落间距，让视线从一行移动到下一行，也为理解留出一点空间。

代码示例可用于自己的页面。

其他组件：差分、表单与数学

新增和删除除了使用不同颜色，还保留 + 与 − 标记。

color: #222;color: var(--mb-ink-body);

比例也可以写作 ab。公式继承正文颜色。

相关概念

语义颜色
按用途命名的颜色，例如正文、背景和分隔线。
视觉层级
用字号、字重和间距，帮助读者判断内容的先后。
系统外观
设备当前的浅色或深色设置。页面会自动跟随。
